🔐 怎么获得编辑权限 展开
  1. 在 GitHub 生成一个 细粒度 PAT，只授权本仓库。
  2. 仓库权限勾选 Contents: Read and write。
  3. 把 token 粘贴到右上角输入框，点「授权」，即可编辑并自动保存。
💾 数据存在哪里 展开
  • 所有数据保存在你仓库的 data/progress.json 里。
  • 每次修改都会生成一条 Git 提交记录，可随时回滚任意历史版本。
  • 不依赖任何第三方服务器，数据完全在你自己的仓库中。
